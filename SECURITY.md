# Security Policy

SpareNode currently assumes that the node owner trusts every person allowed to
submit jobs. Containers are not treated as a security boundary for hostile
multi-tenant workloads.

Please do not report suspected vulnerabilities in a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/AlankritVerma01/sparenode/security/advisories/new)
so the problem can be investigated before disclosure.

The latest published prerelease and the current `main` branch are supported
during the prototype phase. Older prereleases do not receive security fixes.
